Iframe only (no script)

Where you cannot add a script (a CMS, a forum, a notebook), embed the player page directly. The program is in the URL fragment: # + encodeURIComponent(base64(utf8(code))), the same as strudel.cc share links, or the compact #z= form TuttiDAW's share menu gives. Without the SDK the iframe does not resize itself, so give it a height.

The markup

<iframe
  src="https://tuttidaw.com/embed/code?theme=dark#c2V0Y3BtKDIwKQpkcnVtczog..."
  title="TuttiCode player"
  allow="autoplay"
  loading="lazy"
  referrerpolicy="strict-origin-when-cross-origin"
  style="border: 0; width: 100%; height: 260px"
></iframe>

To control a bare iframe, post { protocol: 'tuttidaw-embed', version: 1, type: 'play' } to it; see the postMessage protocol.
