Script tag

Load v1.js, then write <tuttidaw-code> anywhere. The program goes in the code attribute (single quotes, so the program's own double quotes need no escaping).

The markup

<script src="https://tuttidaw.com/embed/v1.js" defer></script>

<tuttidaw-code theme="dark" loops="4" show-code code='setcpm(31)
drums: s("bd*4, [~ hh]*4, ~ cp ~ cp").bank("tr909")
bass: note("<[a1 ~ a1 a2] [f1 ~ f1 f2] [c2 ~ c2 c3] [g1 ~ g1 g2]>").s("sawtooth").lpf(600)
master.fx("Limiter")'></tuttidaw-code>

A published snippet, by id

On tuttidaw.com/code, Embed → Publish gives a fixed id: <tuttidaw-code snippet="aB3dE5fG7hJ9"></tuttidaw-code>. A snippet never changes; an edit is published under a new id.
