Vue 3

The TuttidawEmbed plugin from @tuttidaw/embed/vue registers <tuttidaw-code> and tells Vue's template compiler it is a custom element. Bind :code; events are @tuttidaw:*.

{{ status }}

The app

import { createApp } from 'vue';
import { TuttidawEmbed } from '@tuttidaw/embed/vue';

createApp({ data: () => ({ program: '...', status: 'loading' }) })
  .use(TuttidawEmbed)
  .mount('#app');

// template:
// <tuttidaw-code :code="program" theme="dark" @tuttidaw:ended="onEnded" />

With single-file components compiled at build time, also set isCustomElement: (tag) => tag === 'tuttidaw-code' in the Vue plugin's compilerOptions.
